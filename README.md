# Karpathy 从零构建大语言模型实战手册

在线读：[ziyetsui.github.io/karpathy-llm-manual](https://ziyetsui.github.io/karpathy-llm-manual/)

- `index.html`：离线网页版（搜索、勾选清单、图片放大，单文件内嵌全部图片）
- `manual.pdf`：321 页 PDF

这本手册以 Andrej Karpathy《Neural Networks: Zero to Hero》9 节课程的英文自动字幕与官方代码为主干，整理成 13 个可执行步骤：从标量求导、micrograd、bigram/MLP、BatchNorm、手写反传，到字符 GPT、BPE 分词器与 GPT-2 124M 复现。

每个步骤都包含目标、动作清单、做完的标准、白话说明、空间图解、排错表、课程案例、官方原练习与逐课章节时间索引；英文原文一律配中文对照。步骤 3 另有按关键词逐个展开的通俗解释与四张计算示意（计数矩阵、采样的 0–1 尺子、−log(p)、one-hot 与 softmax）。全部 46 条原作者输入（含中文译文与模板）与真实课程截图直接放在对应步骤里。

课程截图与代码版权归原作者 Andrej Karpathy；本手册的中文整理、图表与注解由本书作者编写。完整 124M 训练与真实读者试用未执行。
